Frequently Asked Questions

What tokens can I use in the naming pattern?
You can use {name} for the original file name (without extension), {number} for the padded sequence index, and {date} for today's date stamp (YYYYMMDD).
Are file extensions preserved?
Yes, all file extensions (e.g. .jpg, .pdf, .docx) are automatically maintained unless specifically changed.
How do I receive the renamed files?
All renamed files are packaged into a single ZIP download, keeping your files organized and avoiding dozens of browser download prompts.
