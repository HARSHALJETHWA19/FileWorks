Frequently Asked Questions

Can I zip any file type?
Yes! You can bundle documents, spreadsheets, images, videos, audio clips, code files, and more into standard ZIP archives.
Are these ZIP files compatible with Windows and Mac?
Yes. The generated files use standard DEFLATE compression and can be extracted by Windows Explorer, macOS Finder, iOS Files, Android, and 7-Zip without third-party software.
Are my sensitive files sent to the cloud?
No. FileWorks creates your ZIP archive entirely in your browser using JSZip. Your data is never transmitted across the network.
