Frequently Asked Questions

Why did my merged PDF preserve landscape and portrait pages together?
Unlike basic tools that force all pages into an arbitrary default size, FileWorks preserves each source page's native /MediaBox and /Rotate dictionary entries. If you combine an A4 portrait report with a landscape financial spreadsheet, both pages display in their natural proportions.
Will merging PDFs reduce text clarity or blur vector drawings?
No. FileWorks does not convert your PDF into raster images. All vector line art, CAD drawings, embedded font glyphs, and searchable text streams are copied at 100% original mathematical precision.
Can I merge password-protected PDF files?
PDF encryption restricts programmatic reading of page object streams. If a file is password-protected, please decrypt the file using your authoring tool before merging on FileWorks.
Is there an upload limit or hidden paywall?
FileWorks is 100% free and funded by standard display advertisements. The free tier allows merging up to 3 PDFs per batch (or 8 with ephemeral allowance), with zero accounts or subscriptions required.
