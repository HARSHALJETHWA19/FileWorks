How to Submit a Useful Bug Report

Because FileWorks processes all documents locally in your browser, bugs are almost always related to specific browser memory limits, unsupported format sub-versions (such as encrypted PDFs or unusual image color spaces), or operating system File API quirks.

Please include these details in your email:

  1. Tool Used: (e.g. PDF Split, Image Resize, Create ZIP).
  2. Browser & Operating System: (e.g. Google Chrome v128 on Windows 11, Safari on iOS 17.5).
  3. File Characteristics: File size, page count, or file format (e.g. "a 15 MB 40-page PDF with scanned tables"). Do not send confidential documents.
  4. Exact Error Message: Any toast notification or console error that appeared.
  5. Expected vs Actual Behavior: What you expected the tool to do.

Common Support Questions

Why did my large PDF fail to process on mobile?
Mobile browsers (especially Safari on iOS and Chrome on Android) have strict memory limits for individual browser tabs (typically 500 MB – 1 GB of active heap memory). When processing large multi-page PDFs or generating high-resolution canvases, the device operating system may terminate the tab if memory runs out. For large files over 50 MB, we recommend using a desktop browser.
Why can't I edit or merge a password-protected PDF?
PDF encryption requires the user or owner password to decrypt the object stream and parse internal cross-reference tables. FileWorks respects document security permissions and cannot bypass password protection. Please remove the password using your original document authoring software before processing.
How can I request a new tool or feature?
Send an email to aetherkube@gmail.com with the subject line [Feature Suggestion]. We prioritize features that can be implemented cleanly using client-side Web APIs without requiring backend servers.
Where can I learn how file processing works?
Visit our Learning Center for comprehensive technical guides explaining PDF geometry, image compression math, ZIP security, and browser sandboxing.
