How to Convert PDF Pages to Images: Resolution, DPI, and JPG vs. PNG Trade-Offs

Converting a vector PDF document into a raster image file involves rendering mathematical geometry onto a discrete pixel grid. Here is how DPI scaling works and when to pick PNG over JPG.

⏱️ 6 min read 📅 Updated October 2026 🎯 Intermediate

The Core Difference: Vectors vs. Pixels

A native PDF document contains mathematical descriptions of shapes, curves, and font outlines. When you zoom into a PDF by 800%, the letters remain sharp because the vector engine recalculates the curves at runtime.

An image (JPEG or PNG), by contrast, is a fixed matrix of colored square pixels. When you convert a PDF into an image (a process called rasterization), you must choose two critical parameters:

  1. Resolution (Scale Factor / DPI): How many pixels wide and tall each page should be.
  2. Output Encoding Format: Whether to use lossy JPEG or lossless PNG.

Understanding Resolution: DPI and Canvas Scale Factors

PDF user units default to 72 points per inch. If a standard ISO A4 page (595.28 × 841.89 points) is rasterized at a 1.0× scale (72 DPI), the resulting image is only 595 × 842 pixels. On modern smartphone screens or high-DPI desktop monitors, small 10 pt text will appear pixelated and unreadable.

scale: 1.0 72 DPI 595 × 842 px Quick low-bandwidth thumbnail generation
scale: 2.0 (FileWorks default) 144 DPI (Retina) 1190 × 1684 px Clear, razor-sharp on-screen reading and presentations
scale: 3.0 216 DPI 1786 × 2526 px Detailed schematics, architectural line art, or OCR processing
scale: 4.16 300 DPI 2480 × 3508 px Commercial high-resolution physical printing

JPG vs. PNG: Which Output Format Should You Select?

When to Choose PNG

PNG uses lossless DEFLATE compression. It is ideal for text documents, black-and-white forms, line diagrams, and screenshots. PNG guarantees zero compression artifacts around text characters, preserving perfectly sharp edges.

When to Choose JPG

JPG uses lossy Discrete Cosine Transform (DCT) compression. It is ideal for scanned magazines, brochures, and photo-heavy pages. JPG typically produces files that are 60% to 80% smaller than PNG at equivalent visual clarity.

How FileWorks Converts PDF to Images in the Browser

The FileWorks PDF to Image Tool leverages Mozilla's official PDF.js rendering engine:

  1. The PDF file is loaded into an in-memory typed array.
  2. For each selected page, an off-screen HTML5 <canvas> element is allocated with a scale: 2.0 viewport matrix (144 DPI retina quality).
  3. The PDF vector drawing stream executes on the 2D canvas context using hardware-accelerated browser rasterization.
  4. The canvas is serialized into a high-quality JPEG or PNG Blob using canvas.toBlob().
  5. The canvas memory is immediately released to prevent browser tab crashes on mobile devices.
